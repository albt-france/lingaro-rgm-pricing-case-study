# Measures dictionary

41 DAX measures, grouped in display folders of the `_Measures` table. Generated by `src/build_measures_dictionary.py` from the model definition (`src/build_tmdl.py`). The *Test* column points to [TEST_PLAN.md](TEST_PLAN.md).


## 1 Sales

| Measure | Meaning | Format | Test |
|---|---|---|---|
| **Revenue** | Sales value paid by shoppers (price paid x units). | `$#,0` | T2.2 |
| **Units** | Units sold. | `#,0` | T2.1 |
| **Avg Price** | Average price actually paid, promotions included. | `$#,0.00` | - |
| **Avg Base Price** | Average regular shelf price, weighted by units. | `$#,0.00` | - |
| **Avg Base Price per Oz** | Regular price per ounce (fluid ounce for liquids). Used for pack-price architecture. | `$0.000` | T3.12 |
| **Promo Revenue Share** | Share of revenue sold in promotion weeks (BR-02). | `0.0%` | - |
| **Avg Discount Depth** | Average % below the base price, over promotion weeks with a price cut. | `0.0%` | - |
| **Revenue L52W** | Revenue of the last 52 weeks in the data. | `$#,0` | T2.3 |
| **Revenue P52W** | Revenue of the 52 weeks before that. | `$#,0` | - |
| **Revenue YoY %** | Last 52 weeks vs the previous 52 weeks. | `0.0%` | - |

## DAX

**Revenue**
```dax
Revenue = SUM ( Sales[spend] )
```
**Units**
```dax
Units = SUM ( Sales[units] )
```
**Avg Price**
```dax
Avg Price = DIVIDE ( [Revenue], [Units] )
```
**Avg Base Price**
```dax
Avg Base Price = DIVIDE ( SUMX ( Sales, Sales[base_price] * Sales[units] ), [Units] )
```
**Avg Base Price per Oz**
```dax
Avg Base Price per Oz = DIVIDE ( SUMX ( Sales, Sales[base_price] * Sales[units] ), SUMX ( Sales, RELATED ( Product[size_oz] ) * Sales[units] ) )
```
**Promo Revenue Share**
```dax
Promo Revenue Share = DIVIDE ( CALCULATE ( [Revenue], Sales[is_promo] = 1 ), [Revenue] )
```
**Avg Discount Depth**
```dax
Avg Discount Depth = CALCULATE ( AVERAGE ( Sales[discount_pct] ), Sales[is_promo] = 1, Sales[discount_pct] > 0 )
```
**Revenue L52W**
```dax
Revenue L52W = VAR LastWeek = CALCULATE ( MAX ( Sales[week_end_date] ), REMOVEFILTERS () ) RETURN CALCULATE ( [Revenue], 'Date'[Week End Date] > LastWeek - 364 )
```
**Revenue P52W**
```dax
Revenue P52W = VAR LastWeek = CALCULATE ( MAX ( Sales[week_end_date] ), REMOVEFILTERS () ) RETURN CALCULATE ( [Revenue], 'Date'[Week End Date] > LastWeek - 728, 'Date'[Week End Date] <= LastWeek - 364 )
```
**Revenue YoY %**
```dax
Revenue YoY % = DIVIDE ( [Revenue L52W], [Revenue P52W] ) - 1
```
**Promo Weeks**
```dax
Promo Weeks = CALCULATE ( COUNTROWS ( Sales ), Sales[is_promo] = 1, Sales[baseline_n_weeks] >= 4, Sales[dq_ok] = 1, Sales[baseline_units] > 0 )
```
**Promo Units**
```dax
Promo Units = CALCULATE ( SUM ( Sales[units] ), Sales[is_promo] = 1, Sales[baseline_n_weeks] >= 4, Sales[dq_ok] = 1, Sales[baseline_units] > 0 )
```
**Promo Baseline Units**
```dax
Promo Baseline Units = CALCULATE ( SUM ( Sales[baseline_units] ), Sales[is_promo] = 1, Sales[baseline_n_weeks] >= 4, Sales[dq_ok] = 1, Sales[baseline_units] > 0 )
```
**Incremental Units**
```dax
Incremental Units = [Promo Units] - [Promo Baseline Units]
```
**Promo Uplift %**
```dax
Promo Uplift % = DIVIDE ( [Promo Units], [Promo Baseline Units] ) - 1
```
**Discount Cost**
```dax
Discount Cost = CALCULATE ( SUMX ( Sales, MAX ( Sales[base_price] - Sales[price], 0 ) * Sales[units] ), Sales[is_promo] = 1, Sales[baseline_n_weeks] >= 4, Sales[dq_ok] = 1, Sales[baseline_units] > 0 )
```
**Net Incremental Profit**
```dax
Net Incremental Profit = VAR m = [Margin Value] RETURN CALCULATE ( SUMX ( Sales, Sales[units] * ( Sales[price] - Sales[base_price] * ( 1 - m ) ) - Sales[baseline_units] * Sales[base_price] * m ), Sales[is_promo] = 1, Sales[baseline_n_weeks] >= 4, Sales[dq_ok] = 1, Sales[baseline_units] > 0 )
```
**Promo ROI**
```dax
Promo ROI = DIVIDE ( [Net Incremental Profit], [Discount Cost] )
```
**Post-Promo Dip %**
```dax
Post-Promo Dip % = DIVIDE ( CALCULATE ( SUM ( Sales[units] ), Sales[is_post_promo_week] = 1, Sales[baseline_n_weeks] >= 4, Sales[baseline_units] > 0 ), CALCULATE ( SUM ( Sales[baseline_units] ), Sales[is_post_promo_week] = 1, Sales[baseline_n_weeks] >= 4, Sales[baseline_units] > 0 ) ) - 1
```
**Published Elasticities**
```dax
Published Elasticities = CALCULATE ( COUNTROWS ( Elasticity ), Elasticity[status] = "Published", Elasticity[level] IN { "Category", "Brand", "Product" } )
```
**Avg Elasticity**
```dax
Avg Elasticity = AVERAGE ( Elasticity[elasticity] )
```
**Segments**
```dax
Segments = COUNTROWS ( Elasticity )
```
**Price Change Value**
```dax
Price Change Value = SELECTEDVALUE ( 'Price Change'[Price Change], 0.05 )
```
**Margin Value**
```dax
Margin Value = SELECTEDVALUE ( 'Margin Assumption'[Margin], 0.3 )
```
**Sim Elasticity**
```dax
Sim Elasticity = IF ( HASONEVALUE ( Elasticity[segment_id] ) && SELECTEDVALUE ( Elasticity[status] ) = "Published", SELECTEDVALUE ( Elasticity[elasticity] ) )
```
**Sim Volume %**
```dax
Sim Volume % = VAR e = [Sim Elasticity] RETURN IF ( NOT ISBLANK ( e ), POWER ( 1 + [Price Change Value], e ) - 1 )
```
**Sim Volume % Low**
```dax
Sim Volume % Low = VAR p = [Price Change Value] RETURN IF ( NOT ISBLANK ( [Sim Elasticity] ), MIN ( POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_low] ) ), POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_high] ) ) ) - 1 )
```
**Sim Volume % High**
```dax
Sim Volume % High = VAR p = [Price Change Value] RETURN IF ( NOT ISBLANK ( [Sim Elasticity] ), MAX ( POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_low] ) ), POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_high] ) ) ) - 1 )
```
**Sim Revenue %**
```dax
Sim Revenue % = VAR e = [Sim Elasticity] RETURN IF ( NOT ISBLANK ( e ), POWER ( 1 + [Price Change Value], 1 + e ) - 1 )
```
**Sim Gross Profit %**
```dax
Sim Gross Profit % = VAR e = [Sim Elasticity] VAR p = [Price Change Value] VAR m = [Margin Value] RETURN IF ( NOT ISBLANK ( e ), POWER ( 1 + p, e ) * ( m + p ) / m - 1 )
```
**Sim Gross Profit % Low**
```dax
Sim Gross Profit % Low = VAR p = [Price Change Value] VAR m = [Margin Value] RETURN IF ( NOT ISBLANK ( [Sim Elasticity] ), MIN ( POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_low] ) ), POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_high] ) ) ) * ( m + p ) / m - 1 )
```
**Sim Gross Profit % High**
```dax
Sim Gross Profit % High = VAR p = [Price Change Value] VAR m = [Margin Value] RETURN IF ( NOT ISBLANK ( [Sim Elasticity] ), MAX ( POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_low] ) ), POWER ( 1 + p, SELECTEDVALUE ( Elasticity[ci_high] ) ) ) * ( m + p ) / m - 1 )
```
**Sim Revenue Change**
```dax
Sim Revenue Change = [Sim Revenue %] * SELECTEDVALUE ( Elasticity[base_revenue_52w] )
```
**Sim Gross Profit Change**
```dax
Sim Gross Profit Change = [Sim Gross Profit %] * SELECTEDVALUE ( Elasticity[base_revenue_52w] ) * [Margin Value]
```
**Sim Status**
```dax
Sim Status = IF ( ISBLANK ( [Sim Elasticity] ), "Select ONE segment with a published elasticity (BR-06)", "Published elasticity " & FORMAT ( [Sim Elasticity], "0.00" ) & " (95% CI " & FORMAT ( SELECTEDVALUE ( Elasticity[ci_low] ), "0.00" ) & " to " & FORMAT ( SELECTEDVALUE ( Elasticity[ci_high] ), "0.00" ) & "), price change capped at +/-10% (BR-10)" )
```

```dax
Market Value Share (SIM) = DIVIDE ( SUM ( 'Market Sim'[market_value] ), CALCULATE ( SUM ( 'Market Sim'[market_value] ), REMOVEFILTERS ( Brand[manufacturer], Brand[brand_key], 'Market Sim'[manufacturer], 'Market Sim'[brand_key] ) ) )
```
**Retailer Value Share**
```dax
Retailer Value Share = DIVIDE ( SUM ( 'Market Sim'[retailer_revenue] ), CALCULATE ( SUM ( 'Market Sim'[retailer_revenue] ), REMOVEFILTERS ( Brand[manufacturer], Brand[brand_key], 'Market Sim'[manufacturer], 'Market Sim'[brand_key] ) ) )
```
**Price Index vs Competitors (SIM)**
```dax
Price Index vs Competitors (SIM) = AVERAGE ( 'Market Sim'[price_index_vs_competitors] )
```
**Weighted Distribution (SIM)**
```dax
Weighted Distribution (SIM) = AVERAGE ( 'Market Sim'[weighted_distribution] )
```
**Rows Passing Checks %**
```dax
Rows Passing Checks % = DIVIDE ( CALCULATE ( COUNTROWS ( Sales ), Sales[dq_ok] = 1 ), COUNTROWS ( Sales ) )
```
**Flagged Rows**
```dax
Flagged Rows = CALCULATE ( COUNTROWS ( Sales ), Sales[dq_ok] = 0 )
```
