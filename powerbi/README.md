# Power BI project

| File | What it is |
|---|---|
| `LingaroRGM.pbip` | Power BI project: open this in Power BI Desktop |
| `LingaroRGM.SemanticModel/` | Semantic model in TMDL: 21 tables, 41 measures, 9 relationships |
| `LingaroRGM.Report/` | Report in PBIR: 8 pages, generated by `src/build_report_pages.py` |
| `model.tmdl` | The same model as one `createOrReplace` script for the TMDL view |
| `theme.json` | Report theme: light grey background, white cards, Segoe UI, blue for data, grey for comparison |

All of these are generated by `src/build_tmdl.py` and `src/build_report_pages.py`.

## Open it
1. Run the pipeline first (`python src/run_all.py`, see the main README), so that `data/clean` and `data/output` exist.
2. Turn on the preview features in Power BI Desktop (*File > Options > Preview features*):
   - *Power BI Project (.pbip) save option*;
   - *Store semantic model using TMDL format*;
   - *Store reports using enhanced metadata format (PBIR)*.
3. Open `LingaroRGM.pbip`.
4. If the repository is **not** in `C:\lingaro-case-study`, change the folder: *Transform data > Edit parameters > DataFolder* (end it with `\`).
5. Click **Refresh**.

If the model does not load from the folder, use the TMDL view instead:
1. Open **TMDL view**.
2. Paste `model.tmdl` and click **Apply**.
3. Refresh.

## Model (star schema)
```
                Date ──┐
               Store ──┤
 Brand ── Product ─────┼──> Sales (fact, weekly store x product, with promo baseline)
          Promo Type ──┘          
 Brand, Promo Type ───────> Promo Effectiveness
 Brand ───────────────────> Market Sim (SIMULATED)
 Elasticity ──────────────> Scenario Grid
 Stand-alone result tables: Elasticity Split, Cross Elasticity, Promo Summary, Promo Dip, Cannibalisation, PPA,
                            Pricing Stance, Data Quality
 Parameters: Price Change (-10%..+10%), Margin Assumption (20%..45%)
```
Measures live in `_Measures`, in display folders:
- 1 Sales;
- 2 Promotions;
- 3 Elasticity;
- 4 Simulator;
- 5 Market (SIMULATED);
- 6 Data quality.

See [product/MEASURES_DICTIONARY.md](../product/MEASURES_DICTIONARY.md).
